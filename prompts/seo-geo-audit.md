# SEO/GEO Audit Prompt

```text
Audit one page or content entry using the canonical contract at content-plans/content-pipeline.yaml.

Use Google Search fundamentals as the SEO/GEO baseline; do not invent separate ranking requirements for AI search.
Record content findings as a review-report artifact with reviewType seo. Keep site-wide technical findings in the platform roadmap.
Use src/content-workflow/schemas.ts, run pnpm content:validate, and run pnpm build when generated output changes.
Return evidence, blocking findings, suggested fixes, and the next allowed lifecycle transition.
```
