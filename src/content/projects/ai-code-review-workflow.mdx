## 背景

AI Code Review 的核心不是“让模型替你看代码”，而是把重复、低层次、可规则化的问题前置暴露出来。

## 方案

工作流把静态检查、diff 摘要、规则上下文和人工复核放在同一条链路中，避免模型脱离代码事实做泛泛建议。
