## 风控不是单点服务

交易所风控不是一个独立接口，而是贯穿下单、撮合、持仓、保证金、标记价格和强平链路的约束系统。

## 核心链路

```txt
账户余额 -> 可用保证金 -> 下单校验 -> 撮合成交 -> 持仓更新 -> 风险率计算 -> 强平判断
```

## 关键设计

- 撮合前必须有轻量、确定性的风险校验。
- 持仓和保证金更新需要有清晰的一致性边界。
- 强平系统不能依赖普通业务队列的“最终到达”假设。
- 风控规则需要可回放，方便事故复盘。

## 代码表达

```ts
type RiskDecision = 'allow' | 'reject' | 'reduce_only';

function decideOrderRisk(availableMargin: number, requiredMargin: number): RiskDecision {
  if (availableMargin <= 0) return 'reject';
  if (availableMargin < requiredMargin) return 'reduce_only';
  return 'allow';
}
```
