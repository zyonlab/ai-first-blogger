## 规则先于模型

AI Code Review 的质量取决于输入边界。没有规则上下文，模型很容易给出泛泛建议。

## 最小流程

```ts
type ReviewInput = {
  diff: string;
  rules: string[];
  changedFiles: string[];
};

function shouldAskModel(input: ReviewInput) {
  return input.diff.length > 0 && input.rules.length > 0;
}
```

## 推荐边界

- 只审查当前 diff。
- 明确项目代码规范。
- 将建议区分为 bug、风险、可维护性和风格。
- 保留人工最终决策权。
