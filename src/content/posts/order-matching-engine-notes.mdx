## 核心规则

撮合引擎的基本规则通常是价格优先、时间优先。买单价格越高优先级越高，卖单价格越低优先级越高。

## 简化结构

```ts
type Order = {
  id: string;
  side: 'buy' | 'sell';
  price: number;
  size: number;
  createdAt: number;
};
```

## 工程边界

真实系统还需要考虑持久化、事件发布、失败恢复、风控前置、撮合日志和审计回放。
